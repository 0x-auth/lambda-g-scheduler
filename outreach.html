One sentence: Lambda-G is a K8s scheduler plugin that eliminates stranded resources by aligning pod requests with node capacity using vector math.

The problem: Default K8s scheduler treats 90% CPU / 10% RAM same as 50% / 50%. This strands resources — you pay for RAM nobody can use.

The fix: CPU-heavy pods → steered to RAM-heavy nodes → symmetric exhaustion → zero waste.
